# Reflex Arena Rulesets

Collection of rulesets for Reflex Arena. Used automatically by servers that use [this deployment](https://github.com/furioness/reflex-arena-srv-docker).

## How to add your ruleset (no git, browser only)
### Step 1: Fork this repository
1) Open this repository on GitHub
1) Click Fork (top-right)

GitHub will create your own copy of this repo under your account.
You now work in **your fork**, not the original repository.

### Step 2: Add your ruleset file
Go to your fork

1) Click Add file → Create new file
1) Name the file as ruleset_*.cfg (example: ruleset_chump.cfg)
1) Paste your ruleset contents
1) Scroll down and click Commit changes. You can keep the default message.

Your ruleset now exists in your fork.

### Step 3: Open a Pull Request (Merge Request)

1) In your fork, click Contribute
1) Click Open pull request

  GitHub will compare:  
  Base repository: Nailok/reflex_rulesets  
  Head repository: your fork

3) Add a short description (optional but helpful)
1) Click Create pull request

That’s it.
Your ruleset is now submitted for review.

### Updating your ruleset later

If you want to submit changes again, you must first sync your fork with the original repository.

#### Step A: Sync your fork with upstream
1) Go to your fork on GitHub
1) Click Sync fork
1) Click Update branch

This pulls in any new changes from the main repository, if needed.

#### Step B: Edit your file
1) Open your ruleset file in your fork
1) Click the pencil icon (Edit)
1) Make your changes
1) Click Commit changes

#### Step C: Open a new Pull Request
Repeat the same steps as before:

Contribute → Open pull request → Create pull request

## If you mess something up
That’s fine.

You can always edit your pull request.  
You can always re-sync your fork.  
Nothing you do here can break the original repository except when a pull request is accepted, but this is what review is for.  
GitHub is designed for this workflow.
